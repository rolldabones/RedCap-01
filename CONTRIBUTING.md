# CONTRIBUTING

> **Archived on 26 November 2026.** This repository is read-only and takes no contributions. The text below is kept as it stood. See [DISPOSITION.md](https://github.com/rolldabones/rolldabones/blob/main/DISPOSITION.md).

Thank you for your interest in RedCap-01.

## Purpose

Contributions should strengthen the repository's single governing question:

> Does Enterprise Risk Management improve the decisions that determine whether organizational objectives are achieved?

Avoid expanding the repository into a general ERM framework.

## Principles

Contributions should be:

- evidence-oriented
- practical
- concise
- objective-first
- decision-led
- framework-neutral where practical

## Preferred contributions

- Examples
- Templates
- Worked assessments
- Editorial improvements
- Research references
- Implementation experience

## Please avoid

- duplicating other repositories in the ecosystem
- unnecessary complexity
- unsupported claims
- excessive scoring systems
- documentation for its own sake

The instruction block in [`instructions.md`](instructions.md) is the text of record; the custom GPT it came from was retired on 1 October 2026 and its configuration is Locked. Changes to the block are welcome as proposals for the instrument. A proposal is accepted only after one logged run of the published instructions as a system prompt on a current frontier model that meets [ACCEPTANCE.md](https://github.com/rolldabones/rolldabones/blob/main/ACCEPTANCE.md), recorded in [`tests.md`](tests.md), and ships in a repository release.

## Pull requests

Please explain:

- the problem addressed
- why the change improves decision usefulness
- whether the change is backward compatible
- supporting references where appropriate
