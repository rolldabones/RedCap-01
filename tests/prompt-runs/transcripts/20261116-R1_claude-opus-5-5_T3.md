*Why this improves decisions:* it converts a noted interdependency into an actionable boundary while the dual-running and supplier choices can still be adjusted.

**R3. Add direct trigger escalation (G2).**

*Why this improves decisions:* it aligns escalation speed with the required action, so the five-day commitment can actually be met.

**R4. Close the undefined bands and define warning actions (G3, G6).**
- Adopt one convention for every boundary. Either the warning sits at or inside the acceptable ceiling, or the acceptable ceiling equals the warning.
- Specify a preparatory action at each warning.

*Why this improves decisions:* every out-of-appetite state then has an owner and a response, and executives can read all boundaries the same way.

**R5. Extend boundaries to the objective's measures and to attrition (G4).**
- Set ranges, warnings, triggers and actions for operating margin trajectory, OTIF, complaints per million and staff attrition.
- Set interim margin milestones so trajectory can be monitored before December 2027.

*Why this improves decisions:* it governs outcomes as well as drivers, and catches failure modes the two current boundaries cannot see.

**R6. Complete the scenario set (G5).** State the expected-case margin.

*Why this improves decisions:* it tells executives whether the plan, as designed, achieves the objective, and how much the downside must be mitigated.

**R7. Track ERM value as decision outcomes (G7).**

- Include upside capture, such as actions that move toward the 10.5% upside.
