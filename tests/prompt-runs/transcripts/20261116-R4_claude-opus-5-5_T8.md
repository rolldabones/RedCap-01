## 8. Longer-Term Improvements

- **Calibrate boundaries using scenarios.** Base the downside, central and upside paths to 500,000 on management's own data rather than single-point estimates, so thresholds reflect a credible range rather than false precision.

- **Run post-decision reviews** of the region-entry decision and billing migration outcomes, and recalibrate boundaries from what is learned. *Why:* it closes the learning loop and builds the evidence of value.
- **Re-review the appetite** at a defined interval (to be set by the board) and whenever a trigger fires.
